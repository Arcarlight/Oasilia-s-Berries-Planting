# 怎么用这些提示词

这里每个 `.md` 文件都是**自包含**的：人设、文风要求、硬约束、待润色的文件全文，
全部在里面。你不需要自己拼。

## 步骤

1. 打开一个文件，**全选复制**，整段粘到 Gemini 网页端，发送。
2. 它会回一份**完整文件**（末尾的【输出要求】里明确要求了这点）。
3. 把回复给我，我来合并、做结构校验、跑测试。

## 给我结果的两种方式

**方式一（推荐）**：直接把回复贴到对话里发我，我落盘。
**方式二**：把回复存成文件放进 `data_raw/gemini_out/`，文件名用：

```
data_raw/gemini_out/regulars_r1_2.js      ← 对应 01
data_raw/gemini_out/regulars_r3_4.js      ← 对应 02
data_raw/gemini_out/regulars_r5_6.js      ← 对应 03
data_raw/gemini_out/regulars_r7_8.js      ← 对应 04
data_raw/gemini_out/regulars_r9_10.js     ← 对应 05
data_raw/gemini_out/atlas.js              ← 对应 06
data_raw/gemini_out/regions.js            ← 对应 07
data_raw/gemini_out/main.js               ← 对应 08
data_raw/gemini_out/ui.js                 ← 对应 09
```

存完跟我说一声，我全部接手：结构校验（id/性格/口味/解锁条件一条都不许变）、
语法检查、逐页签自检、单元测试、合并、提交、推上线。

## 我会替你把关什么

Gemini 有可能顺手改了不该改的东西（数值、id、结构）。所以合并前我会跑：

- `node --check` —— 语法
- 与润色前快照逐条对拍 —— id / 性格 / 口味 / 讨厌口味 / 解锁条件 / 台词条数
- 逐页签自检 —— 八个页签逐页渲染，任何一页报错都能抓出来
- 单元测试 + 48 小时长线模拟 —— 数值曲线有没有被带歪

有问题的我改回来再合并，不会直接把它的输出盖到项目上。
