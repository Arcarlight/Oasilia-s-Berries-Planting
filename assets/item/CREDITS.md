## 果酱按口味换色（5 个）

`jam_辣.png` / `jam_涩.png` / `jam_甜.png` / `jam_苦.png` / `jam_酸.png`

以 **化け猫缶 素材屋** 的罐子（#0284）为底，按五个口味的主题色换色相：

| 口味 | 色调 |
|------|------|
| 辣 | `#e05635` |
| 涩 | `#714fda` |
| 甜 | `#ff9861` |
| 苦 | `#77d2e2` |
| 酸 | `#e9d93f` |

做法（`tools/recolor_jam.py`）：转 HSV，**只动饱和度高的那部分**（果酱本体），
色相换成目标、明度原样保留（这样高光和阴影还在）；盖子和标签是低饱和的，
原样不动。饱和度压到目标的 82%，配合整体偏灰的调子。

授权上没问题：化け猫缶 明确允许加工，且加工后再配布也自由。

> 之前 `jam.png`（百科的「甜甜蜜」）是五个口味共用的占位图，现在只在
> `productSprite` 兜底时才会用到。
