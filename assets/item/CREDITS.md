## 按口味换色的四类（各 5 张，共 20 张）

`jam_*.png` / `juice_*.png` / `wine_*.png` / `pie_*.png`

以 **化け猫缶 素材屋** 的图标为底，按五个口味的主题色换色相：

| 品类 | 底图 | 换的是哪部分 |
|------|------|-------------|
| 果酱 | #0284 罐子 | 罐身整块 |
| 果汁 | #0394 带液体的茶杯 | 只有杯里的液体（杯子低饱和，留住了） |
| 陈酿果酒 | #0329 高瓶 | 瓶身和标签 |
| 树果派 | #0272 圆扁的果子酥 | 馅和果子 |

主题色：

| 口味 | 色调 |
|------|------|
| 辣 | `#e05635` |
| 涩 | `#714fda` |
| 甜 | `#ff9861` |
| 苦 | `#77d2e2` |
| 酸 | `#e9d93f` |

做法（`tools/recolor_products.py`）：转 HSV，**只动饱和度高的那部分**，
色相换成目标、明度原样保留（这样高光和阴影还在）；低饱和的部分
（盖子、标签、杯壁、酥皮）原样不动。饱和度压到目标的 82%，配合整体偏灰的调子。

挑底图的要点：找"该变色的那部分能被色相替换吃到、不该变的留得住"的图标。

> **看走眼的记录**：一开始给派挑了 `#0277`，以为是"切了一角的派"，
> 其实是**牛排**。而 `#0271`（带盘子的果塔）已经被「挞」占用了。
> 两个库里都没有真正像派的图标，最后选了 `#0272`（圆扁的果子酥）——
> 形状和颜色都能和 `#0271` 那个带盘子的塔分开。
>
> 教训：24×24 缩到 3 倍预览很容易把形状认错，定稿前一律放大 8~10 倍逐个确认。
> 这次是用户在成品上看出来的。

授权上没问题：化け猫缶 明确允许加工，且加工后再配布也自由。

> `wine.png`（果汁牛奶）都是百科来的、五个口味共用的占位图，
